## ✨ Features

- **Manual Flash & Guide-Number (GN) Calculator**: Instantly compute accurate aperture and distance parameters for off-camera manual strobes.
- **Exposure & Reciprocal Calculations**: Quick conversion tools tailored for mechanical cameras and strict lighting constraints.
- **Widget Integration**: Fast-access iOS widgets (`LumiFilmWidget`) for on-the-go field calculations without unlocking your device.
- **Modern Architecture**: Built with pure Swift, leveraging declarative UI patterns and modular project management via `project.yml` (XcodeGen).
