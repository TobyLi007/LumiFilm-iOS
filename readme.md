# LumiFilm 胶片闪光灯精密测光台 (iOS & Home Screen Widget) — v10.7.0

**LumiFilm** 是一款专为胶片摄影师（135 全画幅 / 120 中画幅 / 4×5 大画幅）打造的单手零滚动**机顶闪光灯精密测光与冲扫手账工具**。项目采用全内联 GitHub Actions 工作流（`build_unsigned_ipa.yml`），无需本地 Mac 环境即可在云端自动生成应用图标、编译主程序与桌面交互式小组件，并打包输出可直接通过 **Sideloadly** 免费个人签名的免越狱 `.ipa` 安装包。

## 🌟 v10.7.0 核心亮点与最新升级

1. **满幅渐变消失 3D 机械滚筒轮盘 (`iOSClockDrumWheelView`)**
   - **100% 铺满左下角方格**：采用 `GeometryReader` 自适应铺满左下角 208pt 控制区，消除边缘留白。
   - **真实物理滚轮曲率与首尾渐变消失**：升级 7 槽位（`-3...3`）正弦圆弧轨迹位移（`sin(rad) * radius`）、余弦透视纵向压缩（`cos(rad)`）、3D 桶形透视倾角，以及 `0.0 -> 1.0 -> 0.0` 全幅渐变消失遮罩与上下暗角弧面阴影，配合滚筒横向防滑纹与双侧联动齿轮刻度，逼真还原机械拨轮手感。
   - **零布局跳动**：顶部内置 `26pt` 半透明状态栏，切换至「曝光补偿」时自动在滚轮顶栏右侧显示 `0.0归零` 键，左右双栏严格锁定 `208pt` 高度不发生任何弹跳。
2. **实景相机固定 `1x` 广角主摄 + 同轴 LiDAR 激光雷达点测距**
   - **彻底解决 `0.5x` 变焦下 LiDAR 失准问题**：由于 iPhone 硬件级 LiDAR 激光雷达（`builtInLiDARDepthCamera`）仅与 `1x` 广角主摄同轴校准（`0.5x` 超广角不支持 LiDAR 深度输出且为超焦距镜头），v10.7.0 移除了 `0.5x` 变焦开关，永久锁定 `1x` 广角主摄传感器。
   - **静止点击任意位置毫秒级重采样 + 「🎯 回中心」复位键**：缓存最新一帧 `CVPixelBuffer` 深度矩阵，即使手机完全静止，点击取景画面任意主体即可立即对该坐标的 `5×5` 邻域进行非零有效深度中值重采样；顶栏新增 **「🎯 回中心」** 按钮与 **「❄️ HOLD 锁定」** 按钮并列，一键将点测光/测距准星拉回画面正中心。
3. **首页超大号「闪光输出」核心读数 HUD + 1/3 档 EV 滚轮盲操**
   - 首页中央以 `52pt` 超大字号高亮展示推荐闪光输出档位（`1/1` ~ `1/128`）与残余曝光余量（`±0.1 EV`），同时整合距离、光圈、快门、曝光补偿（`-3.0 ~ +3.0 EV`）、感光度 5 张右侧参数卡。
4. **底层光学物理光损解耦 & 施瓦茨希尔德倒易律失效自动补偿**
   - 严格区分**物理光学损耗**（ND 减光镜 + 柔光罩/跳闪 + 大画幅皮腔延伸）与**闪光同步模式偏置**，锁功率反推距离/光圈精准无偏；当快门处于 `1"` ~ `15"` 夜景慢门档位时，自动按五大胶卷品牌乳剂指数计算倒易律失效延长秒数。
5. **桌面交互式小组件全链路同步 (`LumiFilmWidget`)**
   - 支持 iOS 17+ `Button(intent:)` 桌面步进调参，并通过本地回环桥接（`127.0.0.1:49871`）与共享沙盒同步闪光模式、灯头变焦、迫冲档位、环境光扣减与功率锁状态。

## 📦 编译与 Sideloadly 安装指南

1. 将最新的 `build_unsigned_ipa.yml` 复制替换到 GitHub 仓库的 `.github/workflows/main.yml`（或 `.github/workflows/build_unsigned_ipa.yml`）。
2. 进入 GitHub 仓库的 **Actions** 页面，点击 **Run workflow** 触发云端构建。
3. 构建完成后（约 2~3 分钟），在 **Releases** 或构建详情底部的 **Artifacts** 下载 `LumiFilm-Unsigned-IPA`（内含 `LumiFilm-Unsigned.ipa`）。
4. 打开电脑端 **Sideloadly**，连接 iPhone，拖入 `LumiFilm-Unsigned.ipa`，输入 Apple ID 点击 **Start** 完成签名安装（保持 `Remove limitation on supported devices` 勾选即可兼容个人免费 Apple ID）。
